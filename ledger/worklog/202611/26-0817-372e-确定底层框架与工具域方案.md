## Process

- **架构师**：dsh 的 `src/utils/index.ts:1-18` 是纯具名 barrel、`package.json:29-32` 只出 `./utils`；mp-taro 的 `package.json:47-66` 同时有 `./utils` 和 `./ui/*` 通配双格式，是子路径方案的直接先例；koc 把 moment 藏在 `koc-common-datetimex` 后面（`package-lock.json:16268-16271`），是「第三方封装掩盖依赖」反例。进包判据：是否触碰宿主 API/全局可变状态/时钟/网络。
- **底层开发专家**：`truncateBytes` 两家口径相近但实现不同（dsh `string.ts:18-35` 依赖 `TextEncoder`，mp-taro `string.ts:17-45` 手写码点换算）；相对时间 dsh 拆 past/future 且分到年月（`date.ts:90-104`），mp-taro 单函数只到天且 ≥7 天回退日期（`date.ts:76-88`）；日期解析两家都走本机时区，mp-taro 有 `-`→`/` 的小程序 iOS 兜底（`date.ts:21`）；`formatCount/formatBytes` 两家几乎一致（dsh `number.ts:19-26`、mp-taro `number.ts:18-25`），路径 `extOf/joinPath/parentOf` 对 `?#`、尾斜杠处理不同（dsh `path.ts:27-47`、mp-taro `path.ts:5-21`）。
- **开源框架专家**：三份参考里 dsh 与 mp-taro 都没有直接的 moment/lodash/dayjs/date-fns 依赖（mp-taro 的 lodash 只是传递依赖），koc 则直接依赖 `koc-common-*` 与 `moment ^2.29.1`（`package.json:45-50`）。候选库痕迹仅在本任务前序过程文档 `:21`，三参考零命中。推荐分层：core 自研零依赖；vendor 子路径可选依赖并同时透出上游原版与定制版；date-fns 只放 vendor 且 locale 按需。候选实测未做。
- **成熟框架基线核对（2026-11-26 本轮，来源为官方文档/搜索结果）**：Lodash 官方顶层分类是 Array、Collection、Date、Function、Lang、Math、Number、Object、Seq、String、Util，其中 Date 分类只有 `_.now`，String 分类有 camelCase / kebabCase / snakeCase / trim / truncate 等 28 个函数；es-toolkit 模块是 Array、Function、Math、Object、Predicate、Promise（`delay`）、String，**无 Date 模块**；date-fns 的日期 API 骨架为 add/sub、differenceIn*、min/max/minTime/maxTime、startOf*/endOf*、format*、parse*、is* 比较、formatDistance*/formatRelative；Day.js 有 `minMax` 插件提供 `dayjs.max/min`，`relativeTime` 插件提供 `fromNow/from/toNow/to`。据此最低价只取用户点名的三块；es-toolkit 的 `delay` 只作 sleep 将来落点参考，不进最低价。
- **文档落地（2026-11-26）**：按 `koc-code-docwriter` 走 `init` → `new architecture/overview.md` → `new architecture/directory-structure.md` → 填正文 → `tree` → 补索引说明 → 三篇 `changelog` → `check`。`check` 输出 `[ok] 2 篇文档：槽位、目录树与说明、更新日志、占位符、链接与引用 全过`。生成 `docs/.docwriter.json`（version 1.2.0）与 `docs/README.md`；根 `README.md` 增「设计」节并链接两篇文档。
