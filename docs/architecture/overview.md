# 设计总览

## 1. 系统上下文

| 外部系统 | 方向 | 协议 | 用途 |
|---|---|---|---|
| Node / 浏览器 / 小程序消费方 | 入站 | ESM import | 按函数级子路径引入纯函数 |
| npm registry | 出站 | npm publish（OIDC） | 发布 `dist/` 与类型声明 |
| GitHub Actions | 出站 | tag `v*` 触发 | 构建、自检、发布 |

## 2. 模块与依赖

| 模块 | 职责 | 依赖 | 不能依赖 |
|---|---|---|---|
| `src/string/` | 字符串基础处理 | 无 | 其他域、宿主 API |
| `src/datetime/` | 时间解析、格式化、运算、比较与相对时间文案 | 无 | 其他域、宿主 API、全局语言状态 |
| `tests/` | 验证导出函数行为 | `dist/` | `src/` 源码 |
| `docs/` | 文档索引、设计与目录约定 | 无 | 过程叙事 |

依赖方向固定为：消费方 → `package.json` 函数级子路径 → `dist/` → 函数返回。`src/` 各域之间不互相依赖；具体文件布局见[目录结构](directory-structure.md)。

## 3. 关键链路

### 3.1 子路径导入与调用

1. 消费方从 `js-utils-depot/<域>/<函数>` 导入单个函数。
2. `package.json` 的 `exports` 把该子路径映射到 `dist/<域>/<函数>.js` 与对应类型声明。
3. 函数只依赖入参计算结果；字符串类返回字符串，时间类返回时间值或文案。
4. 非法输入按该函数的签名约定返回回退值；当前唯一实现 `truncateBytes` 对非字符串、非有限或小于等于零的 `maxBytes` 返回空串。

## 4. 部署

| 组件 | 形态 | 副本 | 端口 |
|---|---|---|---|
| `dist/` | npm 包内 ESM 与类型声明 | 不适用 | 无 |

## 5. 不可破的约束

- 必须只暴露函数级子路径；禁止域 barrel 与全量根出口：一次导入不得带进未使用的函数。
- `src/` 必须零运行时依赖；禁止第三方库进入 `src/`：跨端与零依赖是包的基本口径。
- 相对时间必须默认中文，文案可由调用方注入；禁止全局 locale 状态与静态语言包导入。
- 时间函数必须由显式入参决定输出；禁止读取全局可变状态。
- 新增域必须有明确需求，并同步更新 `docs/architecture/directory-structure.md` 与 `package.json` 的 `exports`。

## 6. 术语

| 术语 | 含义 | 别称 |
|---|---|---|
| 子路径 | `package.json` 的 `exports` 中按函数暴露的入口 | 函数级出口 |
| core | `src/` 下不依赖宿主 API 的纯函数集合 | 基础层 |
| 社区化时间表达 | 返回「3分钟前」这类人类可读相对时间的函数 | 相对时间文案 |
